## Projects I'm proudest of

### 📚 DHL Knowledge Base Automation

<img src="https://img.shields.io/badge/Next.js-000000?style=flat-square&logo=nextdotjs&logoColor=white" alt="Next.js" />
<img src="https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white" alt="TypeScript" />
<img src="https://img.shields.io/badge/Supabase-3ECF8E?style=flat-square&logo=supabase&logoColor=white" alt="Supabase" />
<img src="https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white" alt="PostgreSQL" />
<img src="https://img.shields.io/badge/UiPath-FA4616?style=flat-square&logo=uipath&logoColor=white" alt="UiPath" />
<img src="https://img.shields.io/github/last-commit/devMo76/DHL_Automation_Project?style=flat-square" alt="Last commit" />

Logistics information usually lives in messy documents and notes. This app turns it into structured, reviewable knowledge base articles. Users upload PDF, TXT, or DOCX files, a UiPath RPA bot extracts the text through Supabase REST APIs, and the system generates AI-assisted draft articles for a human to review. It also has role-based access, duplicate detection, a status workflow, version history, and audit tracking.

What I'm happiest with: the database security. Access is enforced with Postgres Row Level Security policies (including an admin role) rather than just hiding buttons in the UI.

🔗 [Repo](https://github.com/devMo76/DHL_Automation_Project)

### 🏫 UTM Room Reservation System (CSR Scheduling Assistant)

<img src="https://img.shields.io/badge/PHP-777BB4?style=flat-square&logo=php&logoColor=white" alt="PHP" />
<img src="https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white" alt="MySQL" />
<img src="https://img.shields.io/github/last-commit/devMo76/UTM-Room-Reservation-System?style=flat-square" alt="Last commit" />

A booking system built **with UTM–MJIIT faculty**, not just for a grade. I met with faculty representatives regularly and turned their feedback into changes. Students and staff reserve rooms, track or cancel bookings, and report problems. Admins approve requests, manage users and roles, and see a timetable and dashboard. It works on mobile and desktop.

It includes a REST API, email notifications (PHPMailer/SMTP), PDF reports (FPDF), and the unglamorous security basics: prepared statements, CSRF protection, and bcrypt password hashing. 59 commits over about 7 weeks.

🔗 [Repo](https://github.com/devMo76/UTM-Room-Reservation-System)
